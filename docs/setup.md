# Overview
To run this project, you need to install mininet, ovs, and ryu controller.
Package Versions:
- mininet==2.3.0
- OpenvSwitch==3.5.1
- ryu==4.34

## Installation 
# Step 1: install mininet
Find mininet source packet and install mininet.

# Step 2: uninstall OpenvSwitch
Find the command to uninstall mininet built-in OpenvSwitch.

# Step 3: install custom OpenvSwitch
Download OpenvSwitch source code, edit it to enable stochastic switching, and install it.

# Step 4: install ryu controller.
Download ryu controller and install it. You don't need to edit anything about the ryu controller.

# Step 5: test if everything works.
